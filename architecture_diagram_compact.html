Apigee Security Gateway (Policy Enforcement & Credential Airlock)
1. Auth & Rate Guard
VerifyAPIKey, Bearer mapping, SpikeArrest (10/s), dual Quota buckets per product.
2. RBAC & Product Scopes
Operation allowlist check. Blocks Reader from write ops before target execution.
3. Threat & Payload Shield
SQLi/XSS regex screening, JSONThreatProtection, Model & Channel allowlists.
4. Encrypted KVM Vault
Target PreFlow: Strips client key, injects upstream PAT, Slack Token, or LLM Key.
5. Outbound Redaction Engine (DLP)
PostFlow: Scrubs secret tokens, API keys, credentials, and PII from upstream responses before returning to Agent.
Unified Asynchronous Audit: PostClientFlow logs caller context, key fingerprint, action, and redacted payload to Cloud Logging (agent-airlock-audit).
