End-to-End Hop and Protocol Details
Hop From (Source) To (Destination) Protocol & Port Authentication & Header Transformation
Hop 1a agent-reader / agent-operator agent-airlock MCP Server stdio JSON-RPC Local standard I/O streams; Model Context Protocol (MCP) JSON-RPC messages
Hop 1b agent-reader / agent-operator (LiteLLM) Application Load Balancer (ALB) HTTPS (TLS 1.3 : 443) Authorization: Bearer <consumer_key> targeting /llm/v1
Hop 2 agent-airlock MCP Server Application Load Balancer (ALB) HTTPS (TLS 1.3 : 443) x-api-key: <consumer_key> targeting /github/v1 or /slack/v1
Hop 3 Application Load Balancer (ALB) Network Endpoint Groups (NEGs) HTTPS / PSC Internal URL-map path dispatching to backend NEGs (/llm/v1/*, /github/v1/*, /slack/v1/*)
Hop 4 Network Endpoint Groups (NEGs) Apigee X Runtime (eval / eval-group) HTTPS / PSC Attachment Forwarded via Google Private Service Connect (PSC) to Apigee Service Attachment
Hop 5a Apigee Proxy: llm-v1 OpenRouter API (OpenAI Compatible) HTTPS (Port 443) Apigee strips consumer key and injects KVM secret: Authorization: Bearer <openrouter_api_key>
Hop 5b Apigee Proxy: github-v1 GitHub REST API (api.github.com) HTTPS (Port 443) Apigee strips consumer key and injects KVM secret: Authorization: Bearer <github_pat>
Hop 5c Apigee Proxy: slack-v1 Slack Web API (slack.com/api) HTTPS (Port 443) Apigee strips consumer key and injects KVM secret: Authorization: Bearer <slack_bot_token>
